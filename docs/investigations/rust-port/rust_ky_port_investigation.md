## Run 5 — 2026-10-14 23:08 (reading for correctness: TS findings)

**Command.** `npx tsx .probe/ky/findings.mts`. Rust reproduces each; the inputs are in probes/ky.txt.

**Raw finding.**
1. **No stress is marked at all.** kyrgyz.ts's header says "Stress is final-syllable (Turkic default; unmarked in
   the referee → folded)", but `phonemizeWord` emits no `ˈ` anywhere: `Бишкек шаары` → *biʃkek ʃɑːrɯ*. Every other
   Turkic engine here marks final stress. Whether the omission is deliberate (the referee folds it) or a gap
   between the docstring and the code is for the TS side to say.
2. **No scale above milliard**: 10¹² → *bir miŋ milliɑrd* ("one thousand billion"); `триллион` is in the symbol
   tier's magnitude list but not in the compositor.
3. **A dot decimal loses its separator** (`(\d+)\.(\d+)` → `$1 $2`): `2.5 версия` → *eki beʃ versijɑ*, two bare
   numbers. az reads *nöqtə*, kk *нүкте*.
4. **The `=` rule moves барабар up to 40 characters right**: `а = б жана в ушундай болот` → *а б жана в ушундай
   болот барабар*, the verb placed after the rest of the clause.
5. **A single comma group is a pause**: `12,345 адам` → *on eki , yt͡ʃ d͡ʒyz …* (only two or more `,ddd` groups are
   de-grouped, and `,ddd` is not a 1–2 digit decimal).

**Implication.** Reported in the PR, not fixed. Nothing port-pending.
