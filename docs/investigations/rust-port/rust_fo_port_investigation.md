# Rust port: Faroese (fo)

Part of #1463, the "north" group (fi, et, hu, is, fo). Method as in rust_fi_port_investigation.md.

Faroese is a greedy grapheme scan where the stressed vowel's LENGTH (open/closed syllable, ⟨ð⟩ not counting)
selects its QUALITY, then the skerping remaps, the consonant passes (geminates and ⟨ll⟩→[tl], hv/hj, Cj, g/k
affrication, the ð/g glide by its neighbours, v-vocalisation, retroflex r-clusters, final unstressed -um) and the
nasal pass; a normalizer resolving the five jobs of the full stop; the shared symbol tier; and numbers through the
shared UNITS-FIRST compositor in `src/languages/danish/unitsFirstNumbers.ts`. No initialism pass, no lexicon, no
neural entry, no `ROMAN_POLICIES` entry. **FLEURS has no Faroese**, so the golden (200 texts) and the synthetic
probes are the whole of the text input — see Run 3 for what they reach.

**Implication.** Port danish/unitsFirstNumbers → numbers → normalize → faroese.

## Run 2 — 2026-10-14 23:22 (first build, and a defect in the port's own source)

**Command.** `cargo build --release -p parity && ./target/release/parity fo`.

**Raw finding.**
- `fo: 200/200 identical, 0 differ` once `pub mod danish` was registered.
- ⚠ **The editing tool had rewritten regex escapes into characters.** `grep -P '[\x{00a0}\x{202f}\x{2009}]'` over
  the new Rust found `[ \u00a0\u202f\u2009]` written as four literal characters in faroese/normalize.rs, and the
  same in finnish/normalize.rs and hungarian/normalize.rs (both already committed) — while every TS source writes
  the ESCAPES. The match is identical, which is why no differential could see it; the code points are not, which
  is the rule. Restored with `perl -CSD` (byte-level, so the tool cannot rewrite it back) in all three, plus the
  same fold in the dump.mts lines this group added (JS strings: values unchanged). Then an audit,
  `north/audit_regex.py`: every raw-string pattern in the five modules occurs verbatim in its TS source (the only
  non-matches are `format!` templates, checked by hand against the TS template literals). Re-run after the
  restoration: `fi-normalize 36034 / hu-normalize 20611 / phonemize-sync fi,hu,fo 8227`, 0 DIFFER each; parity
  unchanged.
- Pre-existing, NOT this group's: the same literal-character form is in belarusian, bulgarian, catalan, dutch,
  czech, croatian and galician normalize.rs (`grep -P` lists them). Not touched here; reported.

**Implication.** The audit is part of every language's gate from here on.

## Run 3 — 2026-10-14 23:26 (per-module differentials, then end to end)

**Commands.** New `dump.mts` entries `fo-normalize` and `fo-g2p` (no `FLEURS_DIR` entry: there is none), one
`fn-diff` arm, run through `north/e2e.sh`. Inputs: the golden and the new synthetic `probes/fo.txt`.
- `fo-normalize`: per text, `normalizeFaroese`, the recorded symbol tier over its output, and the whole
  `createFaroese().text` (so the synthetic rows reach the tokenizer's decimal-comma number branch too); synthetic
  rows: the leap-second grid (7 hours × 3 minutes × 4 seconds), both grouping separators and the decimal dot, 12
  abbreviations × 5 tails (mid-sentence, sentence-final, before `)`, a capital, a quote), the ordinal period
  before a lowercase word / a capital / an NBSP, degrees, signs, ranges.
- `fo-g2p`: `phonemizeWord` over every letter run, every 1–3 letter string of 37 letters, every 4-letter string over
  `aeiouóðgkjrnvhm` (the length count, skerping, the glide, affrication, retroflexion, -um), corners; the
  nativiser; `numberToWords` (0…20,000, magnitudes to 10¹², corners, raw strings) — the units-first compositor.
- end to end `LANGS=fo` `phonemize-sync`, `phonemize-best`, `phonemize-trace`, `trace`; `SYMBOLS_LANGS=fo symbols`.

**Raw finding.** First build, every one:
```
fo-normalize: 1224 identical, 0 DIFFER  (golden 600 / probe 42 / synthetic 582: three ops per text)
fo-g2p: 238412 identical, 0 DIFFER
phonemize-sync / phonemize-best / phonemize-trace / trace: 214 identical, 0 DIFFER each
symbols: 3272 identical, 0 DIFFER  (probe 3072 / faroese 200)
```
Reach without FLEURS: every normalize.ts arm has at least one probe line and a synthetic family.

**JS semantics reproduced on purpose.**
- `consonantPasses` blanks a LATER segment's `g` (the second half of a geminate, an absorbed ⟨j⟩), and the later
  iteration then sees the empty `g`: two blanked neighbours compare equal and take the geminate arm, whose
  `CONS[""] ?? s.ph` keeps the phone. The Rust walks the same mutable slice.
- `m[2].split(",")` with the integer part as `raw` (#1080); the fraction read per CODE POINT (`for … of`), each
  digit through `numberToWords(Number(dg))`.
- `RETRO[next.g]` / `PRENASAL[prev.g]` / `CONS[c]` are own-key lookups on object literals; no key a scan can
  produce is an `Object.prototype` member.

**Guard check (reverting a reproduction).** The length count's ⟨ð⟩ exclusion removed:
`fo-g2p: 236051 identical, 2361 DIFFER`. Restored: 0 DIFFER.

## Run 4 — 2026-10-14 23:28 (reading for correctness: TS findings, reported not fixed)

**Command.** `WT=<worktree> N=languages/faroese/normalize.ts FN=normalizeFaroese npx tsx north/t.mts fo <texts>`.

**Raw finding (TS output, verbatim):**
1. **A clock after `kl.` is read as a decimal.** `kl. 14.30 í dag` → normalized `klokkan 14,30 í dag` →
   `klɔkan fjʏɻʈan kɔma tɹʊiː nʊtl …`. Step 3 (the decimal dot, measured only on dollar figures) runs before the
   abbreviation step, and nothing ties `kl.` to the figure after it.
2. **A dotted date's day.month becomes a decimal plus a sentence break.** `Hann kom 23.4.2020 heim` →
   `23,4.2020` → `tɹʊiːɔkt͡ʃʏvʊ kɔma fʊiːɹa . tvɛiː tʉuːsʊnt …`.
3. **A two-digit-year date passes the leap-second rule.** `Føddur 12.10.20 í Havn` → `12 10 20` → three cardinals;
   the rule's only guard is a valid h/m/s range, which every dd.mm.yy with day ≤ 24 satisfies.

**Implication.** Reported in the PR; Rust reproduces all three.
