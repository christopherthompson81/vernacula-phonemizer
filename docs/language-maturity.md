# Language maturity

A per-language reliability reference: **is a language's output trustworthy, and what work (if any) is outstanding?**
This exists because the single most visible number — the referee-corroboration % in
`tools/referee-eval/referee-eval.test.ts` — is a **confounded** signal and a poor proxy for maturity on its own.

## How to read this (why the referee % ≠ maturity)

The referee floors measure folded agreement with an **independent** transcription source (wikipron / epitran /
kaikki). That number is deflated by two things that have nothing to do with our engine:

- **Referee quality.** wikipron/kaikki dumps are noisy: proper nouns, letter-name rows (`A → eɪ`), acronyms,
  taxonomic Latin, and cross-dialect variants (rhotic vs non-rhotic, N-vs-S Welsh, 3-dialect Irish). English
  measures 36% almost entirely for this reason, not because the engine is 64% wrong.
- **Fold ceiling.** We deliberately fold away layers where we are *richer* than the broad referee (length, tone,
  offglide notation) — so real distinctions we get right, and real ones we get *wrong*, can both be invisible to
  the number (Welsh's n/r/l length errors are folded away, for instance).

So a low number can mean a noisy referee, a fold ceiling, **or** genuine work — you tell them apart by the
**residual composition**, not the headline:

- A **systematic segment class** in the residual (e.g. Welsh's `ɨ ≠ i`) → real, fixable work.
- **Diffuse** proper-noun / notation / dialect noise → referee artifact, not a backlog.

Maturity here is therefore judged on **two axes**, read together with the per-language unit test (the committed
correctness anchor) and the bring-up investigation doc:

1. **Core reliability** — is the segmental g2p correct for the input it supports?
2. **Scope / completeness** — are whole subsystems (text front-end, pitch/tone, diacritization, number
   compositor) deferred, narrowing the input it's reliable *for*?

## Verdict legend

| | Meaning |
|---|---|
| ✅ **Reliable** | Trust the output. Deferrals are minor/notation, or the low referee % is just referee noise / a fold ceiling. |
| 🟢 **Reliable · bounded** | Trust the output for the input the orthography determines. A bounded, documented class is **underdetermined by the writing system itself** (an unwritten contrast — glottal stop, stress, ⟨e⟩/schwa) — closed by a lexicon for attested words, with an irreducible OOV tail. Unlike 🟡, this is **not outstanding work**: there is no path, because the distinguishing information is not in the input. A characterized ceiling, not a backlog item. |
| 🟡 **Reliable + lexical tail** | Correct for the bulk; a documented exception/lexicon layer would close a small, *specific* class (open/close mid vowels, loanwords, stress on learned words). Safe, with a known small error rate on those classes. |
| 🟠 **Scope-limited** | Core g2p correct, but a whole subsystem is deferred — reliable only for a *narrower* input (diacritized Arabic; pinyin, not raw Hanzi; segmental, without pitch/tone). |
| 🔵 **In active development** | Not yet at a stable plateau; the bring-up is still adding a core layer. |
| 🔷 **Single-source verified** | Trustworthy, but corroborated against ONE substantial authoritative source/tradition — no independent second source to triangulate. Reliable within that tradition; the caveat is evidence *breadth* (a systematic error shared with the source would go undetected), not output quality. Distinct from ⛔ (no substantial independent attestation) and from ✅/🟢/🟡 (which rest on an *independent* referee). |
| ⛔ **Cannot-verify** | Examined but NOT independently verifiable — no substantial independent attestation exists, and the language is a near-clone of a covered one, so a clone engine and a clone referee agree trivially. Correctness on the shared bulk is asserted, not measured; only the distinctive features are gold-checked. |

**🟡 vs 🟢 — the discriminator:** ask whether the input contains the information needed for the correct output. If the fix is missing code/data (the info *is* in the input, we just haven't written the rule/lexicon) → **🟡** (a path exists). If the input *under-determines* the output (the writing system doesn't encode the contrast) → **🟢** (capped — a lexicon memorises attested words, OOV is a principled coin-flip forever). Note 🟢 is a *word-level* judgment: a homograph resolvable by sentence context (English *read*/*read* via POS) is **not** 🟢, because the disambiguating info *is* in the input at the clause level — Tagalog's final-ʔ (*bata* child [bataʔ] vs robe [bata]) isn't recoverable even from context, only from the word's lexical identity, which is what makes it genuinely capped.

**⛔ vs 🔷 — the discriminator:** is there a large, reliable body of attestation? If the only "source" is circular — a clone of a covered language, or self-referential — → **⛔** (cannot verify; a clone engine and a clone referee agree trivially, e.g. bho). If there's a substantial authoritative source but only ONE tradition/vertical (no *independent* second source to triangulate) → **🔷** (single-source verified — e.g. Wu, corroborated against the 101k-entry Wugniu/Zaonhe tradition). The difference is the volume and quality of attestation, not merely "referee vs no referee."

**Scope — the FIRST gate (before any of the above):** does the language have a **community-adopted written form** to phonemise? A G2P consumes an orthography, so a language must *have* one that its own community uses. Two exclusions follow. (1) A *variety/accent of a covered language* is out of scope — it has no separate ISO code and no separate orthography; it would be an accent-transfer on the parent (Cockney/AAVE/Scots-accent → `en`; not catalogued). (2) A *distinct language with no community-adopted orthography* is also out of scope — choosing a script and a phonology *for* it is prescriptive, not descriptive: it takes a side in the community's own unsettled writing/identity question, flattens dialectal variation, and lends false authority to one made-up standard. **Chittagonian (ctg) was built and then removed on this rule** — a distinct ~13M-speaker language, but primarily *spoken*, with three competing scripts (Bengali/Latin/Arabic) and no adopted standard; producing "Chittagonian canonical IPA" would have imposed the standardisation the community declined. (Contrast the ⛔ Hindi-belt lects bho/awa/hne, which *do* have a community-adopted Devanagari tradition — Awadhi's *Ramcharitmanas*, Bhojpuri's press, Chhattisgarhi's official status — so phonemising them *follows* an existing practice rather than inventing one.) The test is legitimacy (is it written by its community?), not utility (would many people use it?).

## What "outstanding work" concretely means

- **🟠 scope gaps** — a whole *subsystem* deferred (a Hanzi front-end, pitch accent, compound segmentation,
  abjad short-vowel restoration) — are now **all built: no language currently sits at 🟠.** Burmese `my` was the
  last to clear it (🟠→🟡→✅: subsystems, then the rule-based segmental core, then a pronunciation lexicon for the
  lexical tail). The pattern, when a gap recurs, is to feed the engine its supported input and treat the deferred
  layer as absent (not wrong) until built.
- **🟡 lexical tails** are bounded: a specific, enumerable class (mid-vowel height, loanword C-hardening, learned
  stress) that a small exception lexicon closes, while the rule engine is right for everything else. The
  referee-gated lexicon (`docs/investigations/ga_bringup_investigation.md`, `[[vernacula-oracle-lexicon-method]]`)
  is the template for building these when they're worth it.
- **🔷 single-source** and **⛔ cannot-verify** are *evidence* verdicts, not quality ones: the output may be fine,
  but there's only one authoritative source (🔷) or none at all (⛔), so a systematic error could hide. Most of
  these are distinct-but-under-attested languages (the Sinitic dialect stubs, the Hindi-belt clones).
- **✅** languages have no subsystem gap and no systematic residual class — only notation folds, referee noise, or
  a fold ceiling. The low-numbered ✅s (en, ga, ta, ff, vi, ko) are the ones whose referee is the limiting factor,
  *not* the engine; their real correctness anchor is the hand-authored `test/<lang>.test.ts`.

## Maintaining this doc

Not auto-generated (the verdicts are judgment calls). Refresh a row when a bring-up run lands: re-run
`npx tsx tools/referee-eval/eval.ts <code>` for the measured %, read its **residual classes** (systematic → real
work; diffuse → referee noise), and reconcile against the language's investigation doc. The referee % alone is
never the maturity — always pair it with the residual composition and the unit test.
