# ⚠ THE PINS ARE A RECORD, NOT A CONTRACT. A cuDNN LSTM's backward pass uses atomics, so the same
# seeds on the same GPU can still diverge and different hardware certainly will — which is why
# en-g2p-tagger.PROVENANCE.md records the environment of each shipped set of weights rather than
# promising reproducibility. What these pins buy is that a re-run STARTS from the same place.
# ⚠ AND THE TORCH BUILD MUST MATCH THE DRIVER. `+cu124` is what this machine's driver takes; install
# the index-url line for the CUDA your driver supports rather than editing the version here.
#
