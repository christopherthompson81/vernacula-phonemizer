Derived artifacts in this repository:
  src/languages/central-kurdish/lexicon.tsv            2,517 rows — one vowel fact per word
  src/languages/central-kurdish/ckb-bizroke-tagger.int8.onnx   BiLSTM weights (2.3 MB)
  src/languages/central-kurdish/ckb-bizroke-tagger.meta.json   its symbol/tag tables

  Both are restricted to the ONE fact this project lacks: where Sorani's unwritten short /ɪ/ falls.
  The consonant skeleton in every lexicon row is this engine's own rule output, and the tagger's
  entire tag alphabet is "this symbol" / "this symbol + ɪ" — so neither reproduces the upstream's
  transcription SYSTEM, and no source row is recoverable from the model weights. The source lists
  themselves are NOT redistributed here; clone the repository above to rebuild either artifact.
